方案 01 · 網站的 CMS 骨幹

物種頁加關係標籤

每個節點（物種、人、地方、做法、儀器）各自是一頁，只展示自己的鄰里，不展示整張網絡。關係以受控動詞分組成標籤；點擊標籤另一端，便走進下一頁，挖多深由訪客決定。

本示範只用共用示意資料，以 #buffalo 之類的錨點代替正式網址。正式版會加入相片、錄音與影片，並由研究團隊在 CMS 逐條輸入關係。

    在 Webflow CMS 怎樣做

    這一頁就是 Nodes collection 的模板頁。每個節點一個 CMS item，每條關係也是一個 CMS item；關係用兩個 Reference 欄位指向兩端的節點。模板頁放兩個 Relations 清單，按「目前這個節點」篩選，便只顯示自己的鄰里。

    1. 頁頭直接綁定 Nodes 模板頁的欄位。顏色以 Colour token 寫入 style="--nc:…"。
    2. 向外清單Collection List（Relations），Filter：From equals Current Nodes，Sort：Verb。
    3. 向內清單同上，Filter 改為 To equals Current Nodes。
    4. 按動詞分組Webflow 不能原生 group by。每個動詞各放一個清單會超出每頁 Collection List 的數量上限，所以建議單一清單按 Verb 排序，再用一小段 Code Embed 插入分組標題、套上「曾經」的虛線與「衝突」的顏色。
    5. 三個尺度Webflow Tabs 元件，每個分頁放一個 Relations 清單，按對應的 Switch 欄位篩選。沒有內容時用清單內建的 Empty State，寫上「待補：科學家訪談」等。
    6. 定位圖、你走過的路Code Embed。定位圖讀取頁內一個隱藏清單的 data-lat / data-lng；路徑只存在瀏覽器的 sessionStorage，不需要帳戶或後台。

    示意說明　本頁所有關係、來源與狀態都取自共用示意資料（data.js），未經核實的村民口述保留並標示狀態。夜間相機與蛙聲曲線為模擬資料，只為示範介面。
