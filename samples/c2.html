方案 02 · 標誌圖像 · Code Embed（D3）

線的相遇：物種故事線圖

時間由左至右，每條線是一個物種、一群人或一個團體；在同一地帶出現時線就靠攏，靠攏之處便是「結」。人只是其中幾條線。

這個示意版把五個年代、四個地帶粗略排列：可以追蹤單一條線，也可以點開一個結，看誰在場、資料庫中有哪些相應的關係紀錄及其來源與核實狀態。正式版會把時間細分至節氣與潮汐，並讓每個結連到檢查點、訪談片段與影像。

Webflow 做法：以 Code Embed 放入（D3 約 90 KB），讀取由 CMS 的節點表與關係表匯出的 graph.json；各線在每個年代的位置可作為 CMS 欄位，由團隊自行修訂，毋須改程式。
