方案 04 · 首頁導航裝置

節氣潮汐輪

以圓形曆作首頁導航：指針停在今天的節氣，轉動輪盤，就看到「這兩星期」水口有甚麼正在發生，並可沿連結往下讀。下半部是「低潮閘門」：沙白的內容只在退潮時完整打開。真實版本會接上香港天文台潮汐預報、把每段時節連到物種頁，並逐年加入新的物候紀錄。

Webflow 做法：時節活動、村民原話與來源存於 CMS（Calendar Collection，以 Reference 連到物種），面板文字可由 CMS 原生輸出；輪盤、按真實日期轉動的指針和潮汐閘門需以 Code Embed 寫成（原生 SVG 與 JavaScript，不需 D3）。

CMS：活動、原話、來源Code Embed：輪盤、指針、潮汐節氣・農曆・潮汐沙白是檢查點

      沙白在灘上幾乎不移動，是一個檢查點，而不是一條路線。人能否遇見牠，取決於潮水：潮水低於門檻時，下方的沙白卡片才完整打開。

      模擬潮汐，非天文台預報

      這條曲線以正弦函數模擬（週期約 12.42 小時），門檻 0.8 米亦屬示意。真實版本會使用香港天文台最近潮汐站（例如石壁，待確認）的潮汐預報，並按實地量度的灘面高度設定門檻。
