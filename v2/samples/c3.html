方案 03 · 參考 Storying Extinction（University of Idaho）

路徑，或者自由漫遊

兩條策展路徑按次序逐站揭示，沿途遇見未列為重點的生命；不想跟次序的人，可以跳過路徑，直接在地圖上打開全部檢查點。正式版會在每站放入紅外線片段與訪談影片，並加入現場定位與離線底圖，讓導賞員直接帶到水口使用。

Webflow 做法：路徑、站點、檢查點、物種、關係用 CMS Collection（原生，可由團隊直接編輯）；地圖、逐站切換與鍵盤操作以 Code Embed 載入 Leaflet，讀取頁面上隱藏 Collection List 輸出的資料。

示意連線：只表示站點次序，並非實際行走路線

導賞員現場使用

  1. 出發前在有網絡的地方把路線瀏覽一次，讓底圖留在瀏覽器暫存。水口部分位置訊號不穩；底圖載入失敗時，檢查點、編號與連線仍會顯示，可照常帶隊。
  2. 每到一站按「下一站」，或用鍵盤 ← →；投影時多數翻頁器送出的按鍵（PgUp PgDn）亦可切換。
  3. 泥灘站（4.4、3.5）要配合退潮。頁面上的潮位是模擬資料，出發前請以天文台潮汐預報為準。
  4. 預存某一站：網址會記住目前位置（例如 #trail=buffalo&stop=4），可預先把連結存在手機。
  5. 收集補充：參加者遇見清單以外的生命，請記下檢查點編號與時間交回團隊；未核實的說法日後以「村民口述」等標籤公開，不會當作定論。
